# BEASTMODE Gym Website

A modern and responsive gym website designed for BEASTMODE Gym.

## Features

- Modern dark theme
- Responsive design for mobile and desktop
- Hero landing section
- About Us section
- Training Programs section
- Gym Gallery
- Instagram integration
- Contact section

## Technologies Used

- HTML5
- CSS3
- Google Fonts (Poppins)

## Installation

1. Download the project files.
2. Save the main file as `index.html`.
3. Open `index.html` in any web browser.

## Project Structure

```
BEASTMODE-GYM/
│
├── index.html
└── README.md
```

## Customization

### Change Gym Name

Search for:

```html
BEASTMODE Gym
```

Replace it with your gym name.

### Change Instagram Handle

Search for:

```html
@beastmodegym.01
```

Replace it with your Instagram username.

### Change Images

Replace the image URLs inside the `<img>` tags with your own gym photos.
